# Architecture decision records

Each entry gives the context, the decision and its consequences. Add new entries at the end, and never edit old ones;
supersede them instead.

## ADR-001: The document lives in the URL fragment

**Context**: no-registration sharing without trusting a server. **Decision**: encode the whole map into `#/v1/…`.
**Consequences**: no backend, no data breach possible, and links can be long. Size is a core feature (link meter,
Simplify). The browser's history holds maps, and the UI documents this.

## ADR-002: Binary format with quantised delta coordinates, not JSON

**Context**: coordinates dominate size, and JSON with 6 decimals costs about 20 bytes per point. **Decision**: integers at
1e-5°, zigzag varint deltas, deflate when smaller. **Consequences**: about 2 to 4 bytes per vertex. The format is
hand-written and frozen, so it ships finished and tested in the kit instead of being generated by an agent.

## ADR-003: MapLibre GL JS + OpenFreeMap Liberty

**Context**: we need vector maps without API keys or usage-based billing. **Decision**: MapLibre 6 with
`https://tiles.openfreemap.org/styles/liberty`, whose sprite, glyphs and tiles are on the same host.
**Consequences**: one third-party host, disclosed. MapLibre is about 300 kB gzipped and is lazy-loaded.

## ADR-004: terra-draw for editing

**Context**: drawing tools (vertices, snapping, selection) are expensive to build well. **Decision**: terra-draw plus
its MapLibre adapter. It is used only as an input device, and the MapDoc remains the single source of truth.
**Consequences**: a moderate bundle cost and a maintained library with no HTML injection.

## ADR-005: No server in v1

**Context**: Bolt's WebContainer can't run Workers, and every server is a privacy liability. **Decision**: static-only.
Short links and preview cards are deferred. **Consequences**: long links. v2 may add a zero-knowledge short-link
service (ciphertext only, key in the fragment, as in Tiny Little Office's `tinier`).

## ADR-006: React + zustand, plain CSS

**Context**: Bolt is most reliable with React. A CSS-in-JS runtime injects `<style>`, which the CSP forbids.
**Decision**: React 19, one zustand store, and plain CSS files with custom properties. **Consequences**: a small,
predictable stack that is CSP-clean.

## ADR-007: PBKDF2 (600k) + AES-256-GCM for passwords

**Context**: we need WebCrypto-native primitives only, with no WASM. Argon2 is not in WebCrypto. **Decision**: PBKDF2-SHA-256
at 600,000 iterations (the OWASP recommendation), a 16-byte salt, a fresh 12-byte IV per seal, AAD, and a versioned
envelope. **Consequences**: about 0.3–1 s to open a sealed link, which is acceptable. A version byte allows upgrades.

## ADR-008: Strict CSP generated from one allow-list

**Decision**: `src/net/allowlist.ts` produces the CSP header, the meta tag and `_headers`. **Consequences**: adding a
host is one deliberate change, reviewed through this file.

## ADR-009: No geocoding in v1

**Context**: search sends what the user types (often an address) to a third party. **Decision**: none in v1. Users
pan and zoom or import files. **Consequences**: less convenient, but private. Revisit with a self-hosted Photon (opt-in).
