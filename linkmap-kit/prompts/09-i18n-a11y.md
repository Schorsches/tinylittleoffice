# Prompt 09: Languages and accessibility

Read first: AGENTS.md §Code style, docs/ACCEPTANCE.md (09).

## Files

- `src/i18n/index.ts`: a tiny typed i18n with no dependency. `t(key, vars?)` uses `Intl.PluralRules` for plurals, plus a
  `useT()` hook and `setLanguage()`. Catalogs `src/i18n/en.ts` and `src/i18n/de.ts` are typed so a missing key in `de` is
  a type error. Write a unit test asserting key parity.
- Move every user-visible string into the catalogs. Numbers and dates use `Intl`.
- Language: `navigator.language` by default. A switcher in the header changes it for the session. It's persisted
  only if the user has saved something (then in the same IndexedDB store, key `settings`).
- Set `<html lang>` and `dir` on change. Convert CSS to logical properties (`margin-inline-start`, `inset-inline-start`, …)
  so `dir="rtl"` lays out correctly.
- Accessibility pass: landmarks (header, nav, main), a skip link to the map, `aria-live="polite"` announcements for
  "Point added", "Link copied" and similar, focus returned to the trigger after dialogs close, 44×44 px touch targets,
  and contrast ≥ 4.5:1 in light and dark themes.
- **New dev dependency allowed**: `axe-core@4.14.0`. Add a small helper `src/test/axe.ts` (`await axe.run(container)`, expect no violations) and use it in the existing component tests.
